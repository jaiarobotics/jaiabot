Jaiabot log explorer

Recorded sensor data from Jaiabot UUVs. Each panel shares a time axis — drag any time panel to zoom, double-click to reset. Rate panels show a per-bin min/max band with the mean line on top, because body rates oscillate near 1.7 Hz and a single decimated line would hide that.

Why the estimator is tuned the way it is

Each panel below pairs a measurement across all logs with the constant it justifies. Parameter values are read out of the source headers at build time, so this cannot drift from the code. Where a constant is looser than the measurement, that margin is deliberate and visible.
